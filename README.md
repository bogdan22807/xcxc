# Atelier North

A premium boutique digital studio landing page — static HTML, CSS, and minimal JavaScript.

## Features

- Slow floating hero animation with smooth easing
- Fully responsive layout (desktop, tablet, mobile)
- Mobile: image below text, scaled typography, full-width buttons, 2×2 statistics grid
- Restrained palette, editorial typography, no template tropes

## Run locally

Open `index.html` in a browser, or serve the directory:

```bash
python3 -m http.server 8080
```

Then visit [http://localhost:8080](http://localhost:8080).

## Live site

**https://bogdan22807.github.io/xcxc/**

The site is deployed to the `gh-pages` branch automatically on every push to `main`.

### If you see 404

GitHub Pages must be enabled once in repository settings:

1. Open [Settings → Pages](https://github.com/bogdan22807/xcxc/settings/pages)
2. **Build and deployment → Source:** Deploy from a branch
3. **Branch:** `gh-pages` → folder `/ (root)` → **Save**
4. Wait 1–2 minutes, then refresh the site URL

### Если видите 404
