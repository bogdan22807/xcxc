# Бублик — выпуск 15 «Морковка»

Вертикальный ролик 1080×1920 по тем же правилам, что выпуск про Эйфелеву башню: факт в первую секунду, кадр на каждую короткую реплику, свой звук на действие, субтитры цветом говорящего, своя музыка.

Голос собран бесплатно: Бублик спокойнее, Пончик выше и быстрее. Кредиты ElevenLabs и Higgsfield не тратились.

## Собрать ещё раз

```bash
cd bublik
python3 tools/build_reel.py scripts/15.segments.json output/bublik_15_morkovka.mp4
```

Нужны `ffmpeg`, Pillow, numpy и пакет `gTTS` (нужен интернет на время озвучки).

Обложка: `output/bublik_15_cover.png`. Текст для поста лежит рядом с роликом, в `.txt`.

Публикует ролик только человек. Чужую музыку в файл не кладём.
